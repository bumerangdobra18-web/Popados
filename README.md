# ПОПАДОС — сайт музыкальной игры

Статический сайт без сборщиков и зависимостей: HTML, CSS и немного JavaScript. Расписание, площадка, галерея и FAQ подтягиваются из JSON-файлов в папке `data/`.

**Как обновлять игры, афиши и ссылки на билеты:** [docs/КАК-РЕДАКТИРОВАТЬ.md](docs/КАК-РЕДАКТИРОВАТЬ.md)

## Структура

```
index.html              главная: первый экран, ближайшие игры, как играть, о проекте, корпоративы, FAQ
schedule/index.html     страница «Расписание игр» (все опубликованные будущие игры по месяцам)
404.html                страница «не найдено»
favicon.svg, robots.txt
data/
  events.json           игры — главный файл для организатора
  site.json             площадка, VK, Ticketscloud (token, metaEvent), контакты, форма заявок
  gallery.json          фото и видео для блока «Атмосфера»
  faq.json              частые вопросы
assets/
  css/style.css         все стили; цвета бренда — в начале файла (:root)
  js/app.js             меню, расписание, кнопки Ticketscloud, галерея, FAQ, форма
  fonts/                Unbounded и Manrope (лицензия SIL OFL, файлы рядом)
  img/logo/             логотип: wordmark*.svg, icon*.svg, PNG-иконки
  img/posters/          афиши игр (+ placeholder.svg — заглушка)
  img/gallery/          фото с игр
  img/og-image.png      картинка для превью ссылки в соцсетях
scripts/check.mjs       проверка данных и ссылок перед публикацией
.github/workflows/pages.yml  автопроверка и публикация на GitHub Pages
docs/                   инструкции и лист логотипа
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (включая скрытые `.github` и `.nojekyll`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Сделайте любой коммит в ветку `main` (или запустите workflow вручную во вкладке **Actions**). Через 1–2 минуты сайт будет по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
4. Свой домен (например, `popados.ru`): **Settings → Pages → Custom domain**, затем у регистратора домена добавьте DNS-записи, которые покажет GitHub.

Все пути на сайте относительные, поэтому он одинаково работает и в подпапке `/<репозиторий>/`, и на собственном домене. После выбора постоянного адреса пропишите полный URL в `og:image` в `index.html` и `schedule/index.html` (соцсети не понимают относительный путь картинки превью).

## Локальный просмотр

Данные загружаются через `fetch`, поэтому открывать `index.html` двойным кликом нельзя — нужен простой сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
node scripts/check.mjs   # проверка данных
```

## Ticketscloud

Кнопки покупки используют официальный скрипт виджета `https://ticketscloud.com/static/scripts/widget/tcwidget.js`: он открывает оформление заказа окном поверх сайта по атрибутам `data-tc-event`, `data-tc-token`, `data-tc-lang` (и `data-tc-meta="true"` для мета-события). У каждой кнопки есть обычная ссылка на ту же страницу оформления Ticketscloud, поэтому покупка работает, даже если скрипт не загрузился.

Токен из `site.json` — это публичный токен виджета: официальный скрипт сам кладёт его в адрес окна оформления, которое видит любой посетитель. Это не API-ключ личного кабинета. API-ключи (`Authorization: key ...`) на сайт класть нельзя.
