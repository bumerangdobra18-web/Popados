# Как обновлять сайт ПОПАДОС без разработчика

Всё, что меняется регулярно, лежит в папке `data/`. Править HTML и код не нужно.

| Файл | Что в нём |
|---|---|
| `data/events.json` | Игры: даты, цены, афиши, ссылки на билеты |
| `data/site.json` | Площадка и адрес, VK, Ticketscloud, контакты, форма заявок |
| `data/gallery.json` | Фото и видео для блока «Атмосфера» |
| `data/faq.json` | Частые вопросы |

## Как править файл через сайт GitHub

1. Откройте репозиторий на github.com и перейдите в папку `data`.
2. Нажмите на нужный файл, например `events.json`.
3. Нажмите значок карандаша ✏️ (Edit this file) справа сверху.
4. Внесите изменения.
5. Нажмите зелёную кнопку **Commit changes…**, напишите, что поменяли (например, «Игра 21 ноября»), и ещё раз **Commit changes**.
6. Через 1–2 минуты сайт обновится сам. Ход публикации виден во вкладке **Actions**: зелёная галочка означает «опубликовано», красный крестик — в файле ошибка, сайт остался в прежнем виде. Нажмите на крестик, откройте шаг «Проверить данные и ссылки» — там по-русски написано, что исправить.

> Главное правило JSON: текст в двойных кавычках `"..."`, между записями запятая, после последней записи запятой нет.

## Добавить новую игру

Откройте `data/events.json`. Пустое расписание выглядит так:

```json
{
  "events": []
}
```

Игра с покупкой через Ticketscloud:

```json
{
  "events": [
    {
      "id": "2026-11-21-hity-2000h",
      "title": "ПОПАДОС: хиты 2000-х",
      "date": "2026-11-21",
      "time": "19:30",
      "venue": "НиСплетни Лаунж",
      "address": "Ижевск, ул. Максима Горького, 156",
      "price": 700,
      "image": "assets/img/posters/2026-11-21.jpg",
      "description": "Главные треки нулевых: от поп-хитов до клубных бэнгеров.",
      "ticketscloudEvent": "ID_СОБЫТИЯ_ИЗ_TICKETSCLOUD",
      "ticketUrl": "",
      "published": true
    }
  ]
}
```

Вторая игра добавляется через запятую после закрывающей `}` первой:

```json
{
  "events": [
    { "id": "2026-11-21", "title": "ПОПАДОС: хиты 2000-х", "date": "2026-11-21", "time": "19:30", "price": 700, "ticketscloudEvent": "..." },
    { "id": "2026-11-28", "title": "ПОПАДОС: русский рок", "date": "2026-11-28", "time": "20:00", "price": "от 600 ₽", "ticketscloudEvent": "..." }
  ]
}
```

Порядок записей не важен: сайт сам сортирует игры по дате.

### Что означает каждое поле

| Поле | Обязательно | Пример | Если не указать |
|---|---|---|---|
| `id` | желательно | `"2026-11-21"` | Ничего страшного. Должен быть уникальным |
| `title` | нет | `"ПОПАДОС: хиты 2000-х"` | «ПОПАДОС: музыкальное бинго» |
| `date` | **да** | `"2026-11-21"` (ГГГГ-ММ-ДД) | Игра не показывается |
| `time` | желательно | `"19:30"` | Время не выводится |
| `venue` | нет | `"НиСплетни Лаунж"` | Берётся из `site.json` |
| `address` | нет | `"Ижевск, ул. ..."` | Берётся из `site.json` |
| `price` | нет | `700` или `"от 600 ₽"` | Цена не выводится |
| `image` | нет | `"assets/img/posters/....jpg"` | Фирменная заглушка |
| `description` | нет | `"Тема вечера..."` | Не выводится |
| `ticketscloudEvent` | нет | `"6acea8..."` | — |
| `ticketUrl` | нет | `"https://..."` | — |
| `published` | нет | `true` / `false` | Считается `true` |

Если не указаны ни `ticketscloudEvent`, ни `ticketUrl`, кнопки «Купить билет» не будет: вместо неё карточка покажет «Продажа билетов скоро откроется».

## Изменить дату или цену

Найдите игру в `events.json` и поменяйте значение:

```json
"date": "2026-11-28",
"time": "20:00",
"price": 800,
```

Цена числом (`800`) выводится как «800 ₽». Если нужна фраза, пишите в кавычках: `"price": "от 600 ₽"`.

## Скрыть игру

```json
"published": false
```

Игра исчезнет с сайта, но останется в файле, и её можно вернуть, поставив `true`.

## Удалить прошедшую игру

Прошедшие игры пропадают с сайта автоматически через 3 часа после начала, удалять их не обязательно. Чтобы почистить файл, удалите запись целиком от `{` до `}` вместе с запятой перед ней (или после неё, если запись была первой).

## Заменить афишу

1. Подготовьте картинку горизонтального формата 4:3, например 1200×900 px, JPG или WebP до ~300 КБ. На карточке видна вся картинка, по краям немного обрезается.
2. На GitHub откройте папку `assets/img/posters/` → **Add file → Upload files**, перетащите файл, нажмите **Commit changes**. Имя файла лучше латиницей без пробелов: `2026-11-21.jpg`.
3. В `events.json` укажите путь у нужной игры:

```json
"image": "assets/img/posters/2026-11-21.jpg"
```

Проверка перед публикацией скажет, если файл с таким именем не найден.

## Указать ссылку на билеты

**Вариант 1 — виджет Ticketscloud (рекомендуется).** Покупка открывается окном поверх сайта, человек не уходит со страницы.

1. В личном кабинете Ticketscloud откройте событие и найдите его ID (длинная строка из цифр и латинских букв, как `6acea81717bdb1b133ce0a63`; обычно видна в адресе страницы события и в коде виджета).
2. Впишите его в игру:

```json
"ticketscloudEvent": "ID_события"
```

Токен и язык берутся из `data/site.json`, повторять их в каждой игре не нужно.

**Вариант 2 — любая ссылка.** Если продаёте не через Ticketscloud или хотите вести на отдельную страницу:

```json
"ticketUrl": "https://ссылка-на-покупку"
```

Ссылка откроется в новой вкладке. Работают только адреса с `https://`.

Если указаны оба поля, используется виджет Ticketscloud.

## Площадка, адрес, контакты

В `data/site.json`:

```json
"venue": {
  "name": "НиСплетни Лаунж",
  "address": "Ижевск, ул. Максима Горького, 156"
},
"contacts": {
  "phone": "+7 900 000-00-00",
  "telegram": "@popados",
  "email": "hello@example.ru"
}
```

Пустые контакты (`""`) на сайте не показываются. Ссылка «на карте» строится из адреса автоматически.

## Фото и видео в блоке «Атмосфера»

1. Загрузите фото в `assets/img/gallery/` (JPG/WebP, по длинной стороне 1600 px).
2. Добавьте их в `data/gallery.json`. Первое фото показывается крупно.

```json
{
  "items": [
    { "src": "assets/img/gallery/01.jpg", "alt": "Команды отмечают треки в карточках" },
    { "src": "assets/img/gallery/02.jpg", "alt": "Финал игры" },
    { "src": "assets/img/gallery/03.jpg", "alt": "Видео с игры", "video": "https://vk.ru/video-241897850_000000" }
  ]
}
```

У видео `src` — это обложка, а `video` — ссылка, которая откроется по нажатию. Показываются первые 7 элементов. Пока список пуст, на сайте стоят аккуратные фирменные заглушки.

## Частые вопросы

`data/faq.json`: пары «вопрос — ответ». В ответе можно писать `{venue}` и `{address}` — они заменятся на площадку и адрес из `site.json`.

## Форма заявок на корпоративы

Пока в `site.json` не заполнены `leadForm.endpoint` и `leadForm.privacyPolicyUrl`, форма выключена и предлагает написать во ВКонтакте. Сайт никогда не показывает «заявка отправлена», если сервис приёма заявок не подтвердил получение.

Чтобы включить:

1. Заведите сервис приёма форм, который принимает POST-запрос и хранит или пересылает заявки (почта, Telegram, CRM). Заявки содержат персональные данные, поэтому для граждан РФ выбирайте сервис, который хранит данные в России (152-ФЗ).
2. Опубликуйте политику обработки персональных данных (отдельной страницей или файлом).
3. Заполните:

```json
"leadForm": {
  "endpoint": "https://адрес-приёма-заявок",
  "privacyPolicyUrl": "https://адрес-политики"
}
```

Форма отправляет поля `name`, `contact`, `date`, `guests`, `comment`, `consent`, `source`. В репозитории заявки не сохраняются.

## Если что-то сломалось

- Сайт выглядит как раньше после правки: откройте вкладку **Actions**. Красный крестик — ошибка в данных, текст ошибки в шаге «Проверить данные и ссылки».
- Игра не появилась: проверьте формат даты (`"2026-11-21"`), не стоит ли `"published": false`, не прошла ли дата.
- Любую правку можно откатить: откройте файл → **History** → выберите прошлую версию.
